## AutoPilot은

할 일을 적고 종료 시각을 정한 뒤 **시작**을 누르면, Claude가 그 시각까지 아래 과정을 반복합니다.

1. 적어 둔 작업을 위에서부터 처리하고, 다 끝나면 스스로 고칠 곳을 찾습니다.
2. 고친 내용을 테스트로 확인합니다.
3. 확인을 마친 작업 하나를 commit 하나로 남기고, 무엇을 했는지 기록해 다음 차례로 넘깁니다.

모든 작업은 `ai/autopilot` 브랜치에만 쌓입니다. 돌아와서 리포트와 commit을 훑어보고 마음에 드는 것만 가져가면 됩니다.

## 주요 기능

### 적고, 고르고, 시작

- 작업 칸에 한 줄에 하나씩 적으면 위에서부터 차례로 처리합니다.
- 모델(Fable · Opus · Sonnet · Haiku), Effort(low ~ max), 종료 시각을 화면에서 바로 고릅니다.
- 입력한 값은 다음에 앱을 켤 때 그대로 남아 있습니다.

### 밤새 돌려도 흐트러지지 않습니다

- 일을 짧은 차례(회차)로 나누고 매번 새로 시작합니다. 대화가 길어져 판단이 흐려지는 일이 없습니다.
- 회차마다 진행 상황을 기록해 두고 다음 회차가 이어받습니다. 중간에 PC가 꺼져도 같은 프로젝트로 다시 시작하면 하던 일을 이어갑니다.
- 종료 시각을 지킵니다. 남은 시간이 20분보다 적으면 새 작업을 시작하지 않고, 한 회차가 2시간을 넘기면 끊습니다.
- 더 할 일이 없으면(두 회차 연속으로 commit이 없으면) 종료 시각 전이라도 알아서 끝냅니다.

### 실행 중에도 조절할 수 있습니다

- 모델과 Effort는 실행 중에도 바꿀 수 있고, 지금 회차가 끝난 뒤 다음 회차부터 적용됩니다.
- **종료 신호**는 하던 작업을 마치고 끝내고, 그 뒤에 나타나는 **종료**는 확인을 거쳐 바로 멈춥니다.
- 앱을 다시 켰을 때 그 프로젝트에서 AutoPilot이 아직 돌고 있으면 자동으로 다시 연결합니다.

### 진행 상황이 한눈에 보입니다

- 가운데에 최근 로그 몇 줄이 흘러가고, 누르면 전체 로그와 회차별 결과가 펼쳐집니다.
- 리포트에는 회차별 결과, 걸린 시간, 비용, commit과 바뀐 규모가 한 장에 정리됩니다. 실행 중에도 계속 갱신되며 설정의 **리포트 열기**로 엽니다.

### 사용량 한도까지 챙깁니다

- 프로필 패널에서 Claude 구독의 5시간 한도와 주간 한도 사용률, 리셋 시각을 확인합니다.
- Claude 계정을 여러 개 등록해 두고 실행할 계정을 고를 수 있습니다. 한 계정의 한도가 찼다면 다른 계정으로 바꿔 시작하면 됩니다.
- 한도에 걸리면 실패로 치지 않고 리셋될 때까지 기다렸다가 이어갑니다. 설정에서 **대기한 시간만큼 종료 시각 연장**을 켜면 기다린 만큼 늦게 끝납니다.
- 오류가 나면 5분 · 15분 · 30분 뒤에 다시 시도하고, 그래도 안 되면 헛돌지 않고 멈춥니다. Opus가 응답하지 못하면 Sonnet으로 넘어갑니다.

### 시간 따라 바뀌는 하늘

배경은 지금 시각의 하늘입니다. 낮에는 해와 구름, 해 질 녘에는 노을, 밤에는 그날의 달 모양과 별자리가 보입니다.

## 맡겨도 안전하게

- 작업은 `ai/autopilot` 브랜치에서만 합니다. 브랜치가 없으면 `main`에서 새로 만듭니다.
- 확인을 마친 작업 하나가 commit 하나가 되므로, 마음에 들지 않는 변경은 commit 단위로 버리면 됩니다. commit 메시지에는 `[ap]`가 붙습니다.
- 파일을 지우지 않습니다. 지워야 할 파일은 프로젝트의 `autopilot/recycle_bin`으로 옮겨 두므로 언제든 되살릴 수 있습니다.
- Git 기록을 지우거나 덮어쓰는 명령, 운영 서버·DB 조작, 인증 정보 변경, 새 외부 서비스나 라이브러리 추가는 하지 않습니다.
- 의도를 모르는 코드, 영향 범위를 알 수 없는 변경, 확인할 방법이 없는 변경은 건너뛰고 다른 작업을 고릅니다.
- 프로젝트마다 지켜야 할 규칙이 있다면 그 프로젝트의 `CLAUDE.md`에 적어 두세요. Claude가 그 내용을 따릅니다.

> [!WARNING]
> Claude는 명령을 실행할 때마다 허락을 묻지 않습니다. **믿을 수 있는 프로젝트에서만** 사용하세요.

## 시작하기

### 준비물

- Windows (64비트)
- [Git](https://git-scm.com/)
- Claude Code: 설치한 뒤 한 번 실행해 로그인해 두세요.

### 설치

[Releases](../../releases)에서 `AutoPilot-<버전>-x64.exe`를 받아 실행하면 됩니다. 따로 설치하는 과정은 없습니다.

게시자 서명이 없어 처음 실행할 때 Windows가 경고할 수 있습니다. **추가 정보 → 실행**을 누르세요.

### 사용법

1. 오른쪽 위 **설정**(톱니바퀴)에서 **폴더 선택**으로 맡길 프로젝트를 고릅니다. Git 저장소의 최상위 폴더여야 하고, commit이 하나 이상 있어야 합니다.
2. 가운데에서 모델, Effort, 종료 시각을 고르고 아래 칸에 할 일을 적습니다. 비워 두면 Claude가 스스로 개선할 곳을 찾습니다.
3. **시작**을 누릅니다.
4. 끝나면 **설정 → 리포트 열기**로 결과를 보고, `ai/autopilot` 브랜치의 commit을 검토합니다.

| 정책 | 동작 |

## 자주 묻는 질문

**언제 끝나나요?**\
종료 시각이 되면 끝납니다. 지시개선에서 작업을 다 마쳤을 때, 두 회차 연속으로 바뀐 것이 없을 때, 오류가 계속될 때는 더 일찍 끝납니다. 종료 시각에 하던 회차도 멈추며, commit하지 못한 변경은 프로젝트에 그대로 남겨 둡니다.

**대상 프로젝트에 무엇이 생기나요?**\
`autopilot` 폴더 하나가 생깁니다. 로그와 리포트, 옮겨 둔 파일(`recycle_bin`)이 들어 있고 Git에는 잡히지 않습니다. 로그와 리포트는 30일이 지나면 자동으로 정리됩니다.

**처음부터 새로 시작하고 싶어요.**\
진행 기록은 프로젝트 밖에 따로 보관되어 같은 프로젝트를 다시 실행하면 이어집니다. 새로 시작하려면 설정의 **진행 기록 초기화**를 누르세요. 기존 기록은 프로젝트의 `autopilot` 폴더에 보관됩니다. 작업을 모두 마치고 끝난 실행은 자동으로 초기화됩니다.

**Claude가 한 일을 자세히 보고 싶어요.**\
리포트와 전체 기록에서 회차별로 확인할 수 있습니다. 한 회차의 대화 전체는 로그에 나오는 세션 ID로 프로젝트 폴더에서 `claude --resume <세션 ID>`를 실행해 열어 봅니다.

## 개발

소스에서 실행하거나 직접 빌드하려면 Node.js 22.12 이상이 필요합니다.

```sh
npm ci
npm start      # 앱 실행
npm run dist   # dist/에 포터블 exe 생성
```

구조와 검증 명령, 개발 규칙은 [CLAUDE.md](CLAUDE.md)와 [desktop/README.md](desktop/README.md)에 있습니다.
