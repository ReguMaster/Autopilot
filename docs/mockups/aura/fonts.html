숫자·코드 서체 비교

화면의 숫자 자리(상태 줄 시계, 진행선 시각, 성과 숫자, 일한 양, 종료 시각 고르기)에 후보 서체를 넣어 비교해요. 한글은 모두 Pretendard이고 숫자만 바뀌어요. 파란 테두리가 지금 앱에 들어간 서체예요.

숫자·화면 서체

Inter와 Geist는 한글이 없어 앱에서는 숫자·기호만 이 서체로 쓰고(unicode-range), 한글은 Pretendard가 맡아요. Wanted Sans와 SUIT는 한글까지 있는 서체라 바꾸면 화면 전체 서체가 바뀌어요.

코드·경로·해시 서체

도구 칩, 커밋 해시, 경로, 전체 기록 로그에만 쓰는 고정폭 서체예요.
